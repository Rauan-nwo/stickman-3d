# Новый канал лонгов: гибрид [[paperbillionstv]] и [[stickman-3d]]

Черновик стратегии. Решения, помеченные «предложение», ждут Рауана.

## Что берём у кого
| | Paper Billions | Наш «Стикман 3D» | Гибрид (предложение) |
|---|---|---|---|
| Тема | деньги и технологии, свежие новости | настоящая странная вещь, история | **громкие деньги, аферы, компании — истории, которые не устаревают за неделю**, плюс один-два свежих повода в месяц |
| Сюжет | детектив, главы, «следим за одним предметом» | «чудак и насмешники», расплата в конце | детектив по главам; внутри глав — наши мини-сюжеты с насмешником и расплатой |
| Подача | 160 слов/мин, сценки-реплики 7–10/мин | 228 слов/мин, 3 реплики на ролик | **~165 слов/мин, реплики героев 6–10/мин** своими голосами |
| Картинка | плоское 2D, тёмный нуар, склейка каждые 2.5 с | 2D-человечки в 3D-мире | **2D-человечки в 2.5D/3D-мире с нуарным светом**; см. ниже |
| Длина | 14–24 мин | 60 с | **12–15 мин** (предложение) |

## Длина: 12–15 минут
- У конкурента лучший результат у 20 минут, но три из четырёх успешных — 14–15 минут.
- Производство у нас дороже, чем у ИИ-студии конкурента: короче ролик — больше роликов в месяц.
- 12–15 минут = 1 800–2 500 слов, 6–7 глав по ~2 минуты.

## Визуальный стиль «Стикман Нуар» (предложение)
Наши детально прорисованные человечки (белая круглая голова, толстый контур, шляпа/деталь как имя) + тёмная
кинематографичная палитра конкурента + объём нашего движка. Отличие от конкурента — глубина, свет и камера,
которых у плоского 2D нет; отличие от наших шортсов — нуар, документы, карты, главы.

**Улучшить персонажей:** второй тон тени на одежде, блик на шляпе, складки, мимика с 15+ ртами (уже есть),
поза в 3/4 и сбоку для каждого героя; в лонгах герои — реальные люди с одной узнаваемой деталью.

## Как сделать 12 минут выполнимыми — библиотека шаблонов
Главный урок: 60 с шортса стоили много часов и миллионы токенов потому, что каждый кадр строился с нуля. Для лонга
нужно, чтобы **~70 % экранного времени собиралось из готовых шаблонов**, а дорогие 3D-сцены шли только в хук и
кульминации глав.

| Шаблон | Доля времени | Как делается |
|---|---|---|
| Чёрный экран с фразой (рукописный шрифт) | 8–10 % | код, 0 усилий |
| Карта с маршрутом / точкой | 8 % | один модуль, данные — список точек |
| Доска расследования (фото, нитки, стикеры) | 8 % | модуль, данные — кто с кем связан |
| Документы, досье, письма, чеки | 8 % | модуль, текст подставляется |
| «Цифра крупно» и простые графики | 6 % | модуль |
| Экран телефона / новостной заголовок | 5 % | модуль |
| Здание ночью / окно / офис — типовые локации | 15 % | 5–6 готовых 3D-локаций, переиспользуются во всех роликах |
| Диалоговые сценки двух героев | 25 % | готовая локация + 2 героя + реплики; рот по словам |
| Уникальные 3D-сцены (хук, кульминации) | 15 % | как в шортсах |

## Порядок запуска (предложение)
1. Утвердить нишу, название и стиль.
2. Построить библиотеку шаблонов и 5–6 типовых локаций (разовые затраты).
3. Пилот: один ролик 12 минут, замерить время и токены на минуту.
4. По замеру решить, сколько роликов в месяц реально.
