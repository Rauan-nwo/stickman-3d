# Пайплайн: ролик 1:1 со стилем канала

Цель: Claude делает ролик, который нельзя отличить от работ Рауана. Эталон — [[V001-how-mine-salting-worked]],
правила — [[style-bible]], инструменты — [[anim-skills-catalog]].

## Что закрывает что
| Этап | Инструмент | Статус |
|---|---|---|
| 1. Сценарий по формуле (7 блоков, ~230 слов) | Claude + [[style-bible]] §6 | готово |
| 2. Озвучка ~228 слов/мин | ИИ-TTS (какой — нужно уточнить у Рауана) | нужен голос канала |
| 3. Таймкоды слов | `faster-whisper` (локально) | готово |
| 4. Шотлист «слово = кадр», 35–40 планов | Claude, шаблон шотлиста huashu + `seedance-studio` | готово |
| 5. Листы персонажей (4 героя-архетипа) | `character-sheet` + `gpt-image` | нужен канон героев |
| 6. Ключевые кадры 9:16 | `gpt-image` / Nano Banana | нужен референс стиля |
| 7. Анимация, мультишот 5–15 с | Seedance через `higgsfield-studio` | Higgsfield MCP не авторизован |
| 8. Монтаж + пословные субтитры + музыка/SFX | ffmpeg (ASS-субтитры) или монтажка Рауана | нужен шрифт и музыка |
| 9. Сравнение с эталоном | метрики ниже + `compare.py` из huashu | готово |

## Метрики «неотличимости» (цикл повторяем, пока все зелёные)
| Метрика | Эталон V001 | Допуск | Чем меряем |
|---|---|---|---|
| Длительность | 61 с | 55–65 с | ffprobe |
| Формат | 720×1280, 30 fps | точно | ffprobe |
| Темп речи | 228 слов/мин | ±10 | whisper |
| Жёсткие склейки (scene>0.25) | 20, медиана 2.15 с | ±3 шт, ±0.4 с | ffmpeg scene |
| Планов в хуке 0–3.5 с | 6 | ≥5 | контактный лист 6 fps |
| Смен картинки (`breakdown.py`) | 53, раз в 1.15 с | 45–60 | huashu `breakdown.py` |
| Громкость | −14 LUFS, LRA 2.7 | ±1 LU | ebur128 |
| Подложка в паузах | −20…−28 дБ | без тишины < −40 дБ | silencedetect |
| Субтитры | 1–2 слова, y≈70 %, белый+обводка | визуально 1:1 | кадры бок о бок |
| Персонажи | 2D, белая голова, толстый контур | слепой тест | Рауан |

Последний и главный критерий — **слепой тест**: Рауан смотрит пару «эталон / копия» и не угадывает.

## Что блокирует сейчас
1. Чем реально делается визуал (ИИ-видео? какая модель? 3D-движок?) — (нужно уточнить у Рауана).
2. Голос: какой TTS/голос, или Рауан пишет сам — (нужно уточнить у Рауана).
3. Музыка и SFX: источник библиотеки — (нужно уточнить у Рауана).
4. Шрифт субтитров и чем они делаются (CapCut? Premiere?) — (нужно уточнить у Рауана).
5. Higgsfield MCP требует авторизации, генерации стоят кредитов — бюджет на тесты (нужно уточнить у Рауана).
