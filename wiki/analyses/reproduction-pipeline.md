# Пайплайн: ролик 1:1 со стилем канала

Цель: Claude делает ролик, который нельзя отличить от работ Рауана. Эталон — [[V001-how-mine-salting-worked]],
правила — [[style-bible]], инструменты — [[anim-skills-catalog]].

## Технология: всё кодом (3D + 2D)
Подтверждено Рауаном 2026-11-14: ролики пишутся кодом — 3D-окружение и 2D-анимированные
человечки внутри него. Версия «ИИ-видео» (Seedance/Higgsfield) **отменена**.

Опорный движок из подборки — **anidoodle** (`engine/src/three-core`, three.js 0.170):
- детерминированный рендер кадр-за-кадром → MP4 любого размера, `--format 9x16`;
- камера: `pushIn`, `pullBack`, `dolly`+`path`, `orbit`, `crane`, `truck`, `pan`, `tilt`,
  `whipPan`, моды `handheld`, `dutch`, `zoom`, `rackFocus`, `matchCut`;
- свет и материалы: риги `interior`, `sunset`, `studio`, `night`; `matte`, `satin`, `toon`,
  `glass`, `emissiveGlow`, `outline`, `contactShadow`, `softShadows`, `grain`, `vignette`;
- таймлайн по словам озвучки: `timeline(fps, { words })`, `cue(T, "line:word")`;
- озвучка: `narrate.mjs` (Kokoro бесплатно, ElevenLabs/OpenAI/Gemini по ключу, свои WAV),
  проверка каждого слова whisper'ом, дакинг музыки под голос;
- 2D-слой в 3D: паттерн `textPlane` (2D-canvas → `CanvasTexture` → плоскость в сцене) — так же
  ставятся 2D-персонажи-billboard'ы;
- QA: `gate.mjs` (детерминизм, «мёртвый воздух»), `framecheck.mjs` (safe-зоны 9:16), `ship.mjs`.

Чего в anidoodle нет и надо дописать под наш стиль:
1. **Персонаж-палочник** (круглая голова, руки-палки, тело-капля, набор ртов/глаз/бровей, липфлап
   по таймингу слов) — свой модуль на 2D-canvas, текстура на плоскости в 3D.
2. **Пословные субтитры 1–2 слова** — у anidoodle фразы 2–6 слов (`phrases`), нужен свой режим.
3. **Окружение уровня эталона** — встроенные риги дают «чистый» 3D; для камня/дерева/пыли/лучей
   нужны модели и текстуры (GLTF/PBR) или сильная процедурка — (нужно уточнить у Рауана, откуда ассеты).
4. Сам anidoodle **против гибридов** 2D+3D по умолчанию («читается как два склеенных фильма») —
   гибрид строится только по прямой просьбе; у нас это и есть стиль.

## Метрики «неотличимости» (цикл повторяем, пока все зелёные)
| Метрика | Эталон V001 | Допуск | Чем меряем |
|---|---|---|---|
| Длительность | 61 с | 55–65 с | ffprobe |
| Формат | 720×1280, 30 fps | точно | ffprobe |
| Темп речи | 228 слов/мин | ±10 | whisper |
| Жёсткие склейки (scene>0.25) | 20, медиана 2.15 с | ±3 шт, ±0.4 с | ffmpeg scene |
| Планов в хуке 0–3.5 с | 6 | ≥5 | контактный лист 6 fps |
| Смен картинки (`breakdown.py`) | 53, раз в 1.15 с | 45–60 | huashu `breakdown.py` |
| Громкость | −14 LUFS, LRA 2.7 | ±1 LU | ebur128 |
| Подложка в паузах | −20…−28 дБ | без тишины < −40 дБ | silencedetect |
| Субтитры | 1–2 слова, y≈70 %, белый+обводка | визуально 1:1 | кадры бок о бок |
| Персонажи | 2D, белая голова, толстый контур | слепой тест | Рауан |

Последний и главный критерий — **слепой тест**: Рауан смотрит пару «эталон / копия» и не угадывает.
