# Скилл: Эмоции персонажа (`JohnHeibel/ClaudeAnimationBase`, скилл `clawd-animation`)

Разбор репозитория из [[anim-skills-catalog]] под стиль из [[style-bible]]: 3D-окружение плюс плоские
2D-человечки-билборды, всё кодом, 720×1280, 30 fps. Место в общем конвейере см. в [[reproduction-pipeline]].
Тест проведён 2026-11-14 на этой машине (Windows 11, Node 24.16, Chrome, ffmpeg 8.1, RTX 5050 Laptop).

---

## Название

Наше название: **«Эмоции персонажа»**. Оригинал: Claude Animation Base, стартовый набор для
анимации персонажа Clawd (маскот Claude Code) на p5.js + p5.brush. MIT. У нас стоит как скилл
`~/.claude/skills/clawd-animation` (копия репо + своя обёртка `SKILL.md`). Исходник:
`C:\dev\tools\anim-skills\ClaudeAnimationBase`.

## Установка и запуск

1. Ни в скилле, ни в исходнике не рендерить. Скопировать в рабочую папку (у нас
   `C:\dev\tools\anim-tests\clawd\`).
2. `npm install`: ставит p5 2.3, p5.brush 2.2, puppeteer-core. Заняло ~5 с. Нужны Node, Google Chrome и ffmpeg.
3. Проверка GPU: `node gpu_probe.mjs "C:/Program Files/Google/Chrome/Application/chrome.exe"`.
   Результат у нас: `kit-default` (d3d11) → RTX 5050, `angle-vulkan` → RTX 5050,
   `gl-egl` → Microsoft Basic Render Driver (программный, медленный). `render.mjs` на Windows сам
   берёт `--use-angle=d3d11`, это правильный выбор.
4. Рендер: `node render.mjs --clip --out=out/video.mp4` (демо на 11 с), просмотр: открыть `studio.html`
   в Chrome (`?loop=emotions`, `?loop=views` показывают листы моделей).

Файлы: `src/config.js` (длина, BPM), `src/core.js` (кисти, палитра, тайминг, камера, бумага, рендер-хуки),
`src/clawd.js` (персонаж: виды, эмоции, глаза, рты, шляпы, эмоуты, танцы), `src/timeline.js` (шоты,
лупы, переход-мазок), `src/sheets.js` (листы моделей), `render.mjs` (headless-рендер: листы, стрипы,
кропы, кадры, MP4), `ANIMATION_GUIDE.md` (правила, 461 строка).

## Как пользоваться

### Правила гайда (перевод сути `ANIMATION_GUIDE.md`)

Три цели: **рукотворно** (мазки, «кипящая» линия, плоское 2D, без текста), **живо** (всегда что-то
движется, лица играют, а не переключаются), **цельно** (один фильм, а не набор клипов).

1. **Материал**: всё рисуется через `paint()`/`inkLine()` p5.brush. Персонажи: плоская заливка `wash`
   и чернильный контур. Фон: акварельные `fill`. Обычные p5-фигуры запрещены («выглядит как Flash
   2000-х»). Линия «кипит» 12 раз в секунду (`BOIL`), каждому элементу свой `boilSeed(key)`.
   **3D запрещено**: повороты только нарисованными ключевыми видами (front → q → side → qback → back).
   Свет только через `glow()` (аддитивный, иначе пигмент мешается в грязь).
2. **Без текста**: реакции рисованными знаками (`!`, `?`, zzz, пот, сердечки, лампочка).
3. **В каждом шоте событие**: причина → реакция, одно фокусное действие за раз.
4. **Тайминг под зрителя**: расписать «чтения» (reads) шота: что зритель должен понять, когда
   и сколько времени ему нужно. Одно чтение за раз. Быстрое действие, медленный смысл.
   Это правило модели нарушают чаще всего.
5. **Живость**: у каждой эмоции свой idle на бит (`PROJECT.bpm`). Эмоции меняются только через
   `emotions()`, никогда не переключать `eyes`/`mouth` вручную между кадрами. Персонаж крупный
   (u 20–28 в среднем плане).
6. **Переходы всегда**: мазок (`brushWipe`), ирис (`iris`), вайп-пан, match cut, склейка по действию.
7. **Сначала раскадровка** (`STORYBOARD.md` с логлайном, миром, мотивом, аркой эмоций и чтениями
   по времени), потом код по шоту, потом цикл проверки: контакт-лист → стрип каждого кадра движения
   → кроп лица на полном разрешении.

Принципы анимации из гайда (нам полезны напрямую): упреждение, squash & stretch с сохранением
объёма, slow in/out (никаких голых `lerp`), вес, дуги, захлёст и follow-through (глаза ведут, тело
следует, шляпа догоняет), **против «близнецов»** (руки не синхронно, у персонажей разные фазы),
преувеличение, сильные ключевые позы, видимая мысль.

### API (то, что берём как образец)

```js
// кадр = чистая функция времени: рендер параллельный и не по порядку, состояния между кадрами нет
clawd(x, y, u, feel('happy', t));                                  // одна эмоция, живая
clawd(x, y, u, emotions(t, [[0, 'sleepy'], [1.9, 'surprised', { lookX: .8 }], [2.5, 'idea']]));
clawd(x, y, u, { ...feel('happy', t), ...turn(t, 1, 1.15, 0, .25), hat: 'party' });
```

- `EMO` в `clawd.js`: **31 эмоция**, каждая = `eyes`, `mouth`, тинт/румянец/«мрак», эмоут, `take`
  (сила реакции при входе) и `body(t)` (idle-движение, привязанное к биту через `_b(t)`).
  (В [[anim-skills-catalog]] записано «28», по коду 31.)
- `emotions(t, keys)`: вокруг каждой смены прищур + сжатие (упреждение), лицо меняется под прищуром,
  затем «тейк» по размеру новой эмоции, поза доезжает с overshoot (`backOut`), цвет плавно смешивается,
  эмоут выпрыгивает.
- `eye()`: 24 типа (normal, wide, happy-дуга, closed, wink, narrow, angry, sad, cry, squeeze `> <`,
  scared, spark, heart, x, swirl, shades…). Моргание по `seed`.
- `mouth()`: 16 типов (o, O, smile, grin, flat, wobble, cat, frown, smirk, laugh, open, wail,
  **teeth** с сеткой, tongue, pout, yawn). Липфлапа (смены ртов под речь) в ките **нет**.
- `VIEWS` + `turn()`/`spinView()`: повороты пятью нарисованными видами со смазом (`smear`).
- `stroll()`, `jump()`, `take()`, `spring()`, `ring()`, `arcPt()`, `onTwos()`, `kf()`: движение
  в замкнутой форме от `t`.
- `render.mjs`: `--sheet=0.5,1,2`, `--strip=2:2.5`, `--crop=x,y,w,h`, `--crop-at`, `--stills`,
  `--png` (секвенция), `--frames --workers=N` (параллельно, с докачкой), `--clip`, `--encode`.

## Что даёт для нашего стиля (оценка 0–5)

| Пункт стиля из [[style-bible]] | Что даёт репо | Оценка |

| Смены эмоций без «щелчка» | `emotions()` с упреждением, прищуром, тейком, overshoot | 5 |
| Набор ртов (решётка зубов, O, дуга, черта, смех) | Все формы есть, но нарисованы под Clawd | 3 |
| Липфлап каждые 3–4 кадра | Нет, пришлось писать (`talkMouth`) | 1 |
| Глаза: точки, дуги при смехе, подмигивание, выпученные | Есть все (`dot`, `happy`, `wink`, `scared`) | 4 |
| Брови и усы двигаются | Бровей и усов у Clawd нет | 0 |
| Squash-stretch на смехе, наклон головы | Есть `sq`, `rot`; отдельной головы нет | 3 |
| Руки-палки дугой (rubber hose) | Руки Clawd — прямоугольники | 0 |
| Чистый контур ~4 px, плоская заливка + мягкий градиент | Противоположность: акварель, кипящая линия, бумага | 0 |
| Движение плавное, без «кипения» | Кипение — базовый принцип кита | 0 |
| 720×1280, 30 fps | 1920×1080 и 24 fps по умолчанию (`--fps=30` есть, размер зашит в `core.js`) | 2 |
| Персонаж как билборд в 3D (PNG с альфой) | Рендер всегда на бумаге с зерном, альфы нет | 0 |
| Правила тайминга и анимации (гайд) | Отличный текст, применим к нам почти целиком | 5 |
| Цикл самопроверки (лист / стрип / кроп) | Готовые команды, переносятся в любой движок | 5 |

Итог: **код рисования нам не подходит**, а **архитектура эмоций и гайд подходят полностью**.

## Результат теста

### 1. Оригинальный кит на Windows
- `npm install` ок, `gpu_probe` ок (RTX 5050 через d3d11).
- Демо 0–3 с (`--clip --range=0:3`): 72 кадра за 56 с, **0.6–0.7 с/кадр** (1920×1080, акварель).
- Полное демо 11 с через `--frames --workers=4`: 264 кадра, **~1.0 с/кадр эффективно**, то есть
  4 воркера **медленнее** одного: все дерутся за один GPU. На ноутбуке ставить `--workers=1..2`.
- Лист 31 эмоции (`--loop=emotions --sheet=1`): 6.6 с на кадр.
- Ошибок страницы нет. Файлы: `C:\dev\tools\anim-tests\clawd\out\demo_full.mp4`,
  `...\out\demo_0-3.mp4`, `...\out\emotions_sheet.jpg`.

### 2. Ключевой эксперимент: наш богач на плоском Canvas2D
Написал новый модуль персонажа в духе `clawd.js`, но без p5 и p5.brush: плоская заливка,
один тёмно-коричневый контур 7 px, мягкие градиенты (радиальный на голове и костюме,
линейный на цилиндре), никакого кипения.

- Код: `C:\dev\tools\anim-tests\clawd\src\stick\stick.js` (311 строк), сцена
  `src\stick\scene_rich.js`, страница `stick.html` (открыть в Chrome, крутится в реальном времени),
  рендер `render_stick.mjs`.
- Что внутри модуля:
  - `EMO`: neutral, **talk, laugh, nervous, shock, smug, wink**; у каждой эмоции глаза, рот, брови
    `[подъём, угол]` (раздельно `browL`/`browR` для асимметрии), подъём концов усов, румянец, пот,
    и `body(t)` (позы рук целями кистей, наклон головы, наклон тела, прыжок, squash).
  - `talkMouth(t, set)`: **липфлап**, смена формы рта каждые 3–4 кадра (детерминированно по `hash`,
    без повторов подряд). Проверено по логу кадров: серии 4-4-4-3-3-4.
  - Рты: `teeth`/`teethOpen` (решётка), `O`, `smile`, `flat`, `smirk`, `open`, `laugh`, `laughBig`
    (с языком).
  - Глаза: `dot` (с морганием), `happy` (дуги-щёлочки при смехе), `closed`, `wide`, `half`
    (тяжёлое веко, smug), подмигивание как пара `['happy', 'dot']`.
  - Руки и ноги — `hose()`: квадратичная кривая постоянной длины, сгиб наружу (rubber hose).
    При squash бедро опускается и ноги сами выгибаются.
  - `emotions()` перенесён по смыслу: прищур на смене, упреждающее сжатие, пружинный тейк,
    доезд с overshoot; цилиндр отстаёт пружиной (follow-through), подпрыгивает на шоке,
    приподнимается на подмигивании.
- Рендер: 4 с, 720×1280, 30 fps, 120 кадров. **Отрисовка кадра 0.3–0.8 мс**, всё время уходит на
  PNG и передачу из браузера: **20–50 мс/кадр** (в 15–30 раз быстрее акварельного кита).
- Результаты в `C:\dev\tools\anim-tests\clawd\out\rich\`:
  - `rich_emotions.mp4` (на нейтральном коричневом фоне);
  - `rich_emotions_alpha.webm` (VP9 с альфой);
  - `png\f0000.png … f0119.png` — **RGBA с прозрачным фоном**, готовая текстура билборда;
  - `contact_sheet.jpg` (каждый 6-й кадр, 10×2), `face_strip.jpg` (лица, каждый 3-й кадр),
    `compare_laugh.jpg` (кадр эталона рядом с нашим смехом).

**Насколько близко к эталону** ([[V001-how-mine-salting-worked]], шот 13, 35.7–43.2 с):
- Совпало: силуэт (цилиндр, круглая голова, «боб»-тело, длинные ноги-палки), белый костюм
  с двубортными пуговицами 2×3 и красной розой, усы-руль с завитками, закрытые глаза-дуги и открытый
  рот с языком на смехе, румянец, рука на поясе, мягкая градиентная тень, чистая линия без кипения.
  Узнаётся как тот же персонаж с первого взгляда. Оценка **~75 %** по картинке, **~70 %** по движению.
- Не дотянуто: голова у эталона чуть крупнее относительно тела; лацканы и воротник проще;
  в эталоне кисти более «живые»; жест руки при разговоре выглядит крючком (надо подбирать цели кисти);
  нет поворотов (только фронт) и нет разных ракурсов, у эталона бывает 3/4.

### 3. Проблемы на Windows
- Экранирование фильтров ffmpeg при вызове из Node `spawnSync` без шелла: `select=not(mod(n\,6))`
  разваливается («No such filter '6))'»). Работает только в кавычках: `"select='not(mod(n,6))'"`.
- `gl-egl` и `angle-gl-egl` в `gpu_probe` падают на программный Microsoft Basic Render Driver;
  на Windows использовать дефолт кита (`d3d11`) или `vulkan`.
- Параллельные воркеры на одном ноутбучном GPU замедляют рендер (см. выше).
- Иных проблем нет: пути с `C:/Program Files/...` кит находит сам.

## Ограничения

- Визуальный язык кита (акварель, бумага, кипящая линия, запрет 3D, запрет градиентов «digital glow»)
  прямо противоречит нашему стилю. Из гайда правила 1 и 6 (материал и обязательные переходы) к нам
  **не применимы**: у нас жёсткие склейки и 3D-мир.
- Холст 1920×1080 зашит в `core.js`, альфа-канала нет (всегда бумага и зерно).
- Только один персонаж (блок Clawd) без головы, шеи, бровей, усов, конечностей-палок.
- Нет липфлапа, нет привязки к аудио по словам (есть только BPM).
- Акварель p5.brush медленная: 0.6–1 с/кадр даже на GPU; 60-секундный ролик = 15–30 мин.
- Наш модуль пока одноракурсный (только фронт), без рук-жестов «указать» и без бега/ходьбы.

## Вердикт: роль в стеке

**Как движок рисования: не берём.** Как **образец архитектуры и свод правил: берём обязательно.**

1. Слой «персонажи» в [[reproduction-pipeline]] строим на нашем модуле `stick.js` (Canvas2D,
   флэт + контур + градиент), он доказал, что стиль эталона достижим кодом и рендерится почти мгновенно.
2. Из кита переносим: таблицу `EMO` с `body(t)`, `emotions()` с упреждением и overshoot,
   принцип «кадр = чистая функция `t`», `spring`/`take`/`jump`/`arcPt`, цикл самопроверки
   (контакт-лист → стрип → кроп лица).
3. Из гайда берём правила тайминга (чтения), принципы анимации и «против близнецов» в чек-лист
   каждого ролика. Правила про акварель, кипение, обязательные переходы и запрет 3D игнорируем.
4. Выход персонажа: PNG-секвенция RGBA 720×1280 (или WebM с альфой) → текстура билборда в 3D-сцене.
   Дальше нужно: остальные три героя (шахтёр, напарник в шапке, эксперт в котелке), ракурс 3/4,
   жесты, ходьба/бег, и привязка липфлапа к таймкодам слов из TTS.
