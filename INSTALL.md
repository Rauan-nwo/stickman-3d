# Установка: инструкция для Claude Code на новой машине

Этот файл — пошаговое задание. Человеку достаточно открыть папку проекта в Claude Code и написать:
**«Прочитай INSTALL.md и установи всё по нему»**.

## Что должно получиться
Проект собирает пробный ролик, скилл `stickman-3d` установлен, и на просьбу «сделай ролик в стиле
стикман 3д» Claude ведёт работу по этапам из скилла.

## Шаги для Claude

1. **Проверь, где ты.** В текущей папке должны лежать `engine/`, `wiki/`, `tools/bootstrap.mjs`. Если проекта
   ещё нет — склонируй его: `git clone https://github.com/Rauan-nwo/stickman-3d` и перейди в папку.

2. **Запусти установщик** и дождись конца (первый запуск занимает несколько минут):
   - Windows: `powershell -ExecutionPolicy Bypass -File install.ps1`
   - macOS и Linux: `bash install.sh`

   Он ставит недостающие Node.js, ffmpeg, Python и Chrome, зависимости движка, бесплатный голос edge-tts,
   собирает и устанавливает скилл и рендерит пробный ролик с автопроверкой.

3. **Прочитай итоговую таблицу.** Строки «НЕТ» содержат команду, которая исправляет проблему. Выполни её и
   запусти установщик ещё раз. Частые случаи:
   - программа поставлена, но не видна — нужно открыть новое окно терминала;
   - нет прав на установку — попроси человека запустить команду самому (в Claude Code: `! <команда>`);
   - Chrome не найден — установщик ставит встроенный Chromium, это нормально.

4. **Покажи человеку пробный ролик**: `engine/out/demo/final.mp4` (4 секунды). Если он открылся и в таблице
   всё «OK» — установка закончена.

5. **Ключ ElevenLabs — по желанию.** Без него работает бесплатный черновой голос. Для голосов рассказчика и
   героев и для генерации звуков попроси человека положить свой ключ (начинается с `sk_`) в файл
   `raw/_secrets/voice-api-key.txt`. Папка не попадает в git. Ключ не печатай и не вставляй в команды.

6. **Проверка звука на слух машиной — по желанию**: `node tools/bootstrap.mjs --with-earshot --no-test`
   скачивает earshot в `vendor/earshot`; дальше установка по его README. Без него ролики собираются, не
   работают только скрипты распознавания звуков.

7. **Скажи человеку, что готово**, и предложи начать: «идеи для канала», «сделай ролик в стиле стикман 3д»
   или «продолжаем V002». Дальше работай по скиллу `stickman-3d`: он сам говорит, что читать на каждом этапе.

## Чего в проекте нет после установки
- Готовых видео и звуковых файлов роликов: они не хранятся в git и пересобираются командами из
  `production/V002/HANDOFF.md`.
- Скачанных записей звуков: список и ссылки — в `production/V002/audio/CREDITS.md`.
- В нескольких звуковых скриптах V002 остались пути машины автора (`C:/dev/tools/…`, `C:/Users/velar/…`):
  при пересборке звука этого ролика замени их на свои.

## Если что-то пошло не так
Не обходи ошибку молча. Скажи человеку, на каком шаге остановился, приведи текст ошибки и предложи
исправление.
