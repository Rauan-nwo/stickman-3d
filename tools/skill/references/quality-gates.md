# Приёмка: что проверить до показа автору

Проходи сверху вниз. Каждый пункт появился из замечания, которое автор канала сделал на первом
прогоне, или из ошибки, найденной при перепроверке. Пункт без проверки = почти наверняка замечание.

## 1. Текст (до озвучки)
| Проверка | Норма |
|---|---|
| Слов | 199–246, цель около 235 |
| Первая фраза | действие + угроза, около 13 слов, начинается с He / She / They |
| Насмешник | говорит шуткой-сравнением, один или два раза |
| Разгадка «You see» | на 64–90 % текста, с бытовым сравнением для зрителя |
| Последняя фраза | образ расплаты, кончается на ударном слове |
| Факты | механизм подтверждён двумя источниками; вымышленное помечено |
| Кадр для каждой фразы | выписан; в нём только настоящие люди и предметы, никаких символов |

## 2. Голос
| Проверка | Норма |
|---|---|
| Длительность | 56–67 с (до 70 с, если автор просил медленнее) |
| Темп | 210–220 слов в минуту; ускорение записи не больше 1.15 |
| Паузы между фразами | 0.15–0.35 с |
| Реплики героев | отдельными голосами, помечены в `words.json` как `voice: "char"` |
| Слова | все на месте: число слов в `words.json` равно числу слов в тексте |

## 3. Картинка — автоматика
| Проверка | Команда | Норма |
|---|---|---|
| Толпы по каждому кадру | `node engine/tools/audit.mjs production/V<NNN>/out/film.html` | обрезанных 0, лишних копий 0, порядок 0 |
| Формат, громкость, события, субтитры | `node engine/tools/qa.mjs production/V<NNN>/out/final.mp4 --ass …/captions.ass --min-dur 56 --max-dur 67` | все строки OK |
| Зрительных событий | там же | 50–60 в минуту |
| Самый долгий спокойный отрезок | там же | до 3.6 с |
| Рывков камеры | по `film.js` | не больше одного в секунду |

## 4. Картинка — глазами
Сделай листы кадров через каждые 0.2 с
(`node engine/tools/shots.mjs production/V<NNN>/out/film.html production/V<NNN>/out/pass --every 0.2`)
и просмотри **все** листы. Ищи:
- фигуру, разрезанную по прямой; двух одинаковых солдат вплотную; чужую шляпу или затылок на лице;
- героя, нарисованного поверх цепи, доски, столба, которые ближе к камере;
- предмет, который висит рядом с рукой, а не в руке; предмет, распавшийся на части;
- открытый рот у героя, пока говорит рассказчик;
- огромное тёмное пятно у объектива; героя, обрезанного краем кадра; ноги над землёй;
- пустой кадр (небо, песок) дольше полусекунды;
- лица в зоне субтитров (845–955 px по высоте);
- одинаковые лица и позы у всей толпы.

Отдельно — **хук по кадрам** (первые 3.5 с, 10 кадров в секунду): действие видно с нулевого кадра,
проезд без склеек, главный предмет читается в каждой крупности.

## 5. Звук
| Проверка | Норма |
|---|---|
| Громкость | −14 LUFS ±0.5, пик не выше −1.5 dBTP |
| Тишина | нет отрезков тише −40 дБ |
| Разметка | у каждого события из таблицы есть звук, попадание в картинку ±40 мс |
| Свисты на движение камеры | на каждом рывке; слышны, но не перекрывают слова |
| Речь | распознавание по готовому миксу возвращает весь текст |
| Реплики героев | на 15 дБ и более громче подложки |
| Лицензии | только CC0 или public domain; список в `audio/CREDITS.md` |

## 6. Что сказать автору вместе с роликом
- Что проверено автоматикой и что просмотрено глазами (сколько листов из скольких).
- Что не проверено: звук на слух, сходство с каналом по ощущению.
- Известные слабые места списком, без приукрашивания.
- Три вопроса: цепляет ли хук, не суетлив ли темп, понятна ли разгадка.
