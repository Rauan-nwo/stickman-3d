# Стикман 3D: продакшн ролика

Ролик на 56–67 секунд: рассказчик быстро рассказывает историю с настоящим механизмом в основе,
плоские человечки разыгрывают её в объёмном мире. Картинка, звук и субтитры собираются кодом.

Скилл самодостаточен: внутри лежат движок, правила, шаблоны и разобранный пример готового ролика.
Он написан по итогам первого полного прогона, и почти каждое правило ниже — это ошибка, которую
уже пришлось исправлять. Цель — пройти путь без этих кругов.

## 0. Проект

Работа идёт в папке проекта, где есть `engine/` и `production/`.
- Проект уже есть (в нём лежит `engine/README.md`) — работай в нём. Если есть `wiki/craft/` и
  `production/V<NNN>/HANDOFF.md` — прочитай `HANDOFF.md` начатого ролика первым делом.
- Проекта нет — создай: `node <папка скилла>/scripts/setup.mjs <путь к новой папке>`. Скрипт
  копирует движок и шаблоны, ставит зависимости и проверяет, что есть Node ≥ 18, ffmpeg, Chrome и Python.

Не изучай заново то, что уже записано: это главный способ не тратить токены впустую.

## 1. Что читать

Читай только то, что нужно текущему этапу.

| Этап | Файл в `references/` |
|---|---|
| Идея, сюжет, текст | `channel-formula.md`, `script-craft.md` |
| Постановка | `staging-and-camera.md` |
| Вид героев и мира | `style-bible.md` |
| Сборка | `engine-README.md`, пример `assets/example-V002/film.js` |
| Звук | `sound-design.md` |
| Перед показом — всегда | `quality-gates.md` |
| Порядок этапов и уроки | `production-workflow.md` |

Пример целого ролика — `assets/example-V002/`: текст, постановка, фильм, настройки голосов,
журнал правок. Смотри в него, когда не знаешь, как что-то записать.

## 2. Этапы

Остановись и получи согласие автора канала в четырёх точках: **идея, текст, неподвижные кадры
героев и локаций, готовый ролик**. Текст правится за минуту, пересборка сцены — за час, поэтому
дешёвое утверждается раньше дорогого. Между точками работай без вопросов.

1. **Идея.** Настоящая странная вещь со скрытым смыслом. Проверь семью вопросами из
   `channel-formula.md`. Запиши три строки: действие первого кадра с угрозой, механизм, образ расплаты.
   Если просят варианты — дай 3–5 и скажи, какой берёшь и почему. ✋
2. **Факт-чек.** Два независимых источника на механизм; сохрани со ссылками. Отдельно запиши, что в
   сюжете придумано. Вымысел в истории допустим, выдуманный механизм — нет.
3. **Сценарий.** Английский текст, 199–246 слов, модель «чудак и насмешники». Рядом с каждой фразой —
   что в кадре. Пройди таблицу самопроверки и покажи её вместе с текстом и пересказом на языке автора. ✋
4. **Голос.** Рассказчик один; реплики героев — другими голосами. Целевой темп 210–220 слов в минуту.
   Если выходит длиннее 67 секунд — сокращай текст, а не ускоряй голос сильнее чем в 1.15 раза.
   Время каждого слова сохраняется в `words.json`: по нему строится всё остальное.
5. **Постановка.** Таблица по словам-меткам: локация, переход, камера, действие, эффект, звук.
   Хук — один непрерывный проезд через 4–5 крупностей, действие идёт уже в нулевом кадре.
6. **Вид.** Один неподвижный кадр на каждую локацию и лист эмоций на каждого нового героя. ✋
7. **Сборка.** `production/V<NNN>/film.js` из модулей движка. Все времена — через метки слов,
   секунд в коде нет. Сначала грубая расстановка всего ролика, потом проходы улучшений.
8. **Звук.** Разметка по готовой картинке, пять слоёв, настоящие записи там, где синтез звучит
   пластиково. См. `sound-design.md`.
9. **Приёмка.** Пройди `quality-gates.md` целиком, только потом открывай ролик автору. ✋

После каждого этапа обнови `production/V<NNN>/HANDOFF.md`: что готово, что осталось, какими
командами пересобрать. По нему работу продолжит любая следующая сессия.

## 3. Правила, без которых будут переделки

**История**
- Первая фраза — странное действие и угроза в одном предложении: «He threw his army's only drum
  into the river, with the enemy an hour behind them.»
- Насмешник с властью шутит сравнением. Разгадка звучит на двух третях, с бытовым сравнением для
  зрителя. Расплата падает на насмешников на последних словах. Титров и призывов нет.
- Чистый вымысел без настоящего факта и объяснение без героя не работают.

**Картинка**
- **Сравнения остаются в словах, в кадре — только настоящие люди и предметы.** Рука, давящая на мост,
  и солдаты, превращающиеся в шарики, были «наглядными метафорами»; автор канала их не понял, обе
  пришлось убирать.
- **Рот героя двигается только на его собственных словах.** Пока о нём говорит рассказчик, он играет
  молча. Иначе кажется, что голос не попадает в картинку.
- **Герои не освещаются сценой.** Голова остаётся чисто белой; свет, туман и свечение на героя не ложатся.
- **Плоский герой перекрывается объёмными предметами перед ним** — цепями, досками, столбами — попиксельно.
- **Предмет в руке — один цельный объект**, который рука действительно держит. На среднем и крупном
  плане он объёмный.
- **Не больше одного рывка камеры в секунду.** Быстрая нарезка только там, где она и есть смысл сцены.
- Зрительное событие в среднем раз в секунду, но ни один кадр не стоит дольше 3.5 секунды.

**Толпы — главный источник брака**
- Фигуры режутся по прямой, двоятся, чужие части ложатся на лица. Это ошибки кода толпы, а не
  отдельных кадров: чини причину.
- После любой правки толпы запускай `node engine/tools/audit.mjs production/V<NNN>/out/film.html` по всем кадрам.
  Счётчики обрезанных, раздвоенных и неправильно упорядоченных фигур должны быть нулевыми.

**Проверка**
- Не верь самооценке, своей и помощников: она завышается. Сам посмотри ленту кадров всего ролика
  (каждый шестой кадр) и хук по кадрам, прежде чем показывать.
- Считай, а не прикидывай: склейки, события, громкость, попадание звука в картинку.
- Звук ты не слышишь. Проверяй его замерами и распознаванием речи по готовому миксу; честно говори
  автору, что на слух не проверено.

**Работа с автором**
- Говори на его языке простыми словами. Показывай промежуточные кадры и путь к файлу; готовое
  видео открывай сам.
- Не выдумывай факты и цифры. Чего не знаешь — так и скажи.
- Ключи доступа храни в `raw/_secrets/`, в git и в ответы они не попадают.

## 4. Как не тратить лишнее

- Новый ролик — это новый `film.js` из готовых модулей. Новый герой — пресет в `engine/src/chars/`,
  новая локация — файл в `engine/src/sets/` на готовых конструкторах. Клади их в движок, а не в ролик:
  следующий ролик соберётся быстрее.
- Помощников запускай только для независимых частей (звук отдельно от картинки) и давай им точное
  задание: что читать, что уже сделано, что считается готовым, какие проверки пройти.
- Смотри листы кадров; полный размер — только для спорных мест.
- Голос кешируется: повторный запуск с теми же настройками ничего не стоит.

## 5. Команды движка

Запускаются из корня проекта. Подробности — `references/engine-README.md`.

```
node engine/tools/new-film.mjs V003 --title "Why Something Works"      # заготовка ролика
python engine/tools/voice.py production/V003                           # бесплатный черновой голос + время слов
python engine/tools/voice_eleven.py production/V003 --voice-id <id>    # голос ElevenLabs + время слов
python engine/tools/voice_cast.py production/V003 --cast production/V003/cast.json --target 65   # реплики героев другими голосами, темп
node engine/tools/make.mjs production/V003                             # рендер → субтитры → звук → автопроверка
node engine/tools/audit.mjs production/V003/out/film.html              # проверка толп по каждому кадру
node engine/tools/shots.mjs production/V003/out/film.html production/V003/out/pass --every 0.2   # листы кадров для просмотра
node engine/tools/qa.mjs production/V003/out/final.mp4 --ass production/V003/out/captions.ass --min-dur 56 --max-dur 67
node engine/tools/compare.mjs --ref <ролик канала.mp4> --ours production/V003/out/final.mp4 --out production/V003/out/cmp
```

Кадр — чистая функция номера кадра: никаких часов, случайность только с фиксированным зерном.
Эффекты сами не гаснут — сбрасывай их в начале каждого кадра. Команда оболочки длиннее восьми тысяч
символов в Windows обрывается: большой скрипт сначала запиши в файл.

## 6. Чего скилл не гарантирует

Он убирает известные ошибки, но не заменяет взгляд автора: первый показ почти наверняка даст
замечания. Картинка мира проще, чем у лучших роликов канала (скалы и земля без мелких деталей).
Звук собирается без прослушивания. Говори об этом прямо, когда сдаёшь ролик.
