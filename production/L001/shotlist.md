пролёт по городу — 1.8 с, любой план — 1.3 с; подпланы пути коробки — по реальным длительностям `scenes/box_path_v2`
(+3D-хвост `box_path`). Гл. 0 и 10 (ведущий) — без титра главы: это рамка ролика, как у конкурента; хук начинается с
картинки, а не с титра. Чёрная карточка дописывается к 60 % плана, цифра досчитывает к 50 % — остаток плана текст
стоит целиком.

**Обозначения.** План: общий / средний / крупно / сверхкрупно / обратная (второй плейт с другой стороны) / вставка
(предмет крупно) / сверху / POV / шаблон <вид> / 3D <что>. Правило: в каждом плане одно событие + лёгкое движение
камеры; две одинаковые крупности подряд запрещены (шаблоны разных видов и разные 3D-планы считаются разными);
реплики — сменой точек, не одним общим. Подписи с именем (нижняя треть) — при первом появлении реального человека,
указаны в колонке «событие». Текст в колонке «текст» — начало куска закадра/реплики, который звучит на этом плане.
