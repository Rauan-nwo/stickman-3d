# L001 — финальный рендер («Стикман Нуар»)

Финал собирается из того же монтажа, что аниматик, но вместо табличек-заглушек в кадре настоящие герои.
Пилот — главы 0 (холодное начало: ресторан, улица, машина) и 1 (ведущий в кабинете). Результат:
`out/ch0_1.mp4` (черновой голос сведён), лист `out/sheet_ch0_1.jpg`, приёмка `out/qa_ch0.jpg`, `out/qa_ch1.jpg`, `QA.md`.

## Как устроено

```
animatic/core.js        ядро монтажа (было телом animatic/film.js): тайминг, плейты, шаблоны, камера наезд/стоп/рывок,
                        вип-пан, события по словам, переходы. Хуки HK — пусто = аниматик как был (проверено попиксельно).
animatic/film.js        аниматик = core без хуков (герои — таблички)
animatic/make_timing.mjs  шотлист + голос -> timing.json и words.json (слова голоса на шкале фильма: кто и когда говорит)
film/film.js            финал = core + хуки: plate(s) -> постановка плана из shots.js; без меток и заметок аниматика;
                        дождь только на улице; вещи-подписи, которые уже нарисованы в кадре, не дублируются
film/shots.js           постановка планов: номер -> рисовальщик (база кадра + действия героев по словам)
film/staging/*.js       конфиги локаций: точки посадки/стойки, масштаб, свет, маски переднего плана, базовые кадры
film/chars.js           новые герои (агенты, агент в зале, официант, юный Дженсен) — на каркасе presetsLong
film/props.js           реквизит (бокал, меню с объективом, полароид, ящик, папки, коробка Nvidia, ключ, ценник, чип, перчатка,
                        бобины, коробка плёнок, планшет, сундук)
film/words.js           рот: липфлап только на словах своего героя
film/render.mjs         рендер глав (не больше 2 Chrome параллельно), голос, mux, контактный лист
film/qa.py              листы приёмки: каждый 3-й кадр, 3 кадра на план, непрозрачность, кто говорит
```

Планы без постановки в `shots.js` рисуются как в аниматике — так главы 2–10 переводятся по одной, остальное не ломается.
Шаблоны (карточки, документы, карты), 3D-клипы и переходы финал берёт у аниматика без изменений.

## Команды

```
node production/L001/animatic/make_timing.mjs                      # тайминг из out/lines_draft.json
node production/L001/animatic/make_timing.mjs --lines out/lines_fish.json   # перетайминг под финальный голос Fish
node engine/tools/build.mjs production/L001/film                   # сборка out/film.html
node production/L001/film/render.mjs --ch 0,1                      # out/ch0_1.mp4 + out/sheet_ch0_1.jpg (~2 мин)
node production/L001/film/render.mjs --ch 0,1 --voice out/voice_fish.mp3   # с финальным голосом
python production/L001/film/qa.py sheets production/L001/film/out/ch0_1.mp4 0,1
python production/L001/film/qa.py mouths 0,1
# непрозрачность: одни герои на чёрном и белом
node engine/tools/render.mjs production/L001/film/out/film.html <dir>/k --stills 1s,11.5s --set solo=k --png
node engine/tools/render.mjs production/L001/film/out/film.html <dir>/w --stills 1s,11.5s --set solo=w --png
python production/L001/film/qa.py opacity <dir_k> <dir_w>
```

Перетайминг — только перезапуск: старт планов, рывки, события и рты берутся из `timing.json` и `words.json`,
в постановке нет ни одной секунды, вписанной руками (кроме долей длины плана, где события нет в голосе).

## Как добавить план (главы 2–10)

1. Есть ли у локации конфиг в `staging/`? Нет — завести по образцу: плейт, точки посадки/стойки (пиксели плейта),
   масштаб `fs` (пикселей плейта на единицу фигуры), свет `noirShade(dir)` по источнику на плейте, полигоны переднего плана,
   базовые кадры `{cx, cy, k}` для общего/крупного/обратной.
2. В `shots.js` — запись `n: x => {...}`: база кадра `camView(V.xxx, cam)` (движение даст грамматика аниматика),
   действие героя из колонки «событие»: время — `s.snap`, `s.ev`, `s.whip`, `W_(x, 'слово')`; рот — автоматически.
3. Если событие уже нарисовано в кадре — добавить вещь в `SKIP_PROPS`, чтобы табличка аниматика не дублировала его.
4. Сборка, кадры `--stills`, полный рендер главы, `qa.py sheets` — и свой просмотр листов (чек-лист `QA.md`).
