# L001 — финальный рендер («Стикман Нуар»)

Финал собирается из того же монтажа, что аниматик, но вместо табличек-заглушек в кадре настоящие герои, а 3D-планы —
нативные рендеры сцен кадр в кадр. Пилот — главы 0 (холодное начало: ресторан, улица, машина) и 1 (ведущий в кабинете).
Результат: `out/ch0_1.mp4` (голос по текущему таймингу сведён), приёмка `out/qa_ch0.jpg`, `out/qa_ch1.jpg`, `out/qa/`, `QA.md`.

## Финальная сборка без потерь (final.mjs) — так собирать финал
1. `clips3d.js` — какие 3D-планы берут нативную сцену (`scenes/<scene>`), с какими `--set` (`shot`, `one`, `dur`), с какого кадра.
   `dur: true` — сцена рендерится длиной ровно в план; `group` — несколько планов одним дублем (длина = сумма их кадров).
2. `final.mjs` рендерит эти сцены кадрами PNG 1920×1080 (`render.mjs --stills --png`) в `out/tmp/c3d/<план>/`, затем снимает
   фильм кадрами PNG прямо из браузера (`--allow-file-access-from-files`): в 3D-планах фильм кладёт нативный кадр 1:1
   (без масштаба, без смены частоты, без «дыхания» и пыли аниматика), поверх — подписи и название ролика.
   Кадры идут трубой в ffmpeg: **одно кодирование** x264 crf 16, preset slow, yuv420p; куски склеиваются без перекодирования.
3. `verify3d.py` — проверка вклейки: PSNR выхода к эталону и к нативному кадру (> 40 дБ), кадр 1:1 по пикселям, порядок кадров,
   повторы кадров по всему ролику.
Аниматик оставляет свои прокси (12 к/с, 960×540) — это нормально для черновика, в финал они не попадают.

```
node engine/tools/build.mjs production/L001/film
node production/L001/film/final.mjs --ch 0,1            # ~10 мин; 2 браузера
python production/L001/film/verify3d.py production/L001/film/out/ch0_1.mp4
python production/L001/film/qa.py sheets production/L001/film/out/ch0_1.mp4 0,1
python production/L001/film/flicker.py production/L001/film/out/ch0_1.mp4 production/L001/film/out/ch0_1.frames.json   # final.mjs запускает сам; 0 планов «!!»
```
Ворота мерцания (QA.md §9): никакой модуляции яркости всего кадра быстрее 0.5 Гц и шума кадр-к-кадру; живой свет — только у источника.
`render.mjs` (быстрый рендер через движок, crf 18, 3D — прокси аниматика) остаётся для черновых проверок.

## Плейты финала (make_plates.py)

## Правило хвата (кисть-точка держит предмет)
Кисть — перед предметом и перекрывает его край (у ключа — нижний край головки); предмет уходит от кисти; масштаб реальный
(ключ ≈ 1.8 диаметра кисти — `office.keyGrip`); рука не проходит сквозь и поверх мебели и предметов; рука всегда от плеча героя,
который в кадре (без «рук из-за края» без контекста).

## Как устроено

```
animatic/core.js        ядро монтажа (было телом animatic/film.js): тайминг, плейты, шаблоны, камера наезд/стоп/рывок,
                        вип-пан, события по словам, переходы. Хуки HK — пусто = аниматик как был (проверено попиксельно).
animatic/film.js        аниматик = core без хуков (герои — таблички)
animatic/make_timing.mjs  шотлист + голос -> timing.json и words.json (слова голоса на шкале фильма: кто и когда говорит)
film/film.js            финал = core + хуки: plate(s) -> постановка плана из shots.js; без меток и заметок аниматика;
                        дождь только на улице; вещи-подписи, которые уже нарисованы в кадре, не дублируются
film/shots.js           постановка планов: номер -> рисовальщик (база кадра + действия героев по словам)
film/staging/*.js       конфиги локаций: точки посадки/стойки, масштаб, свет, маски переднего плана, базовые кадры
film/chars.js           новые герои (агенты, агент в зале, официант, юный Дженсен) — на каркасе presetsLong
film/props.js           реквизит (бокал, меню с объективом, полароид, ящик, папки, коробка Nvidia, ключ, ценник, чип, перчатка,
                        бобины, коробка плёнок, планшет, сундук)
film/words.js           рот: липфлап только на словах своего героя
film/render.mjs         рендер глав (не больше 2 Chrome параллельно), голос, mux, контактный лист
film/qa.py              листы приёмки: каждый 3-й кадр, 3 кадра на план, непрозрачность, кто говорит
```

Планы без постановки в `shots.js` рисуются как в аниматике — так главы 2–10 переводятся по одной, остальное не ломается.
Шаблоны (карточки, документы, карты), 3D-клипы и переходы финал берёт у аниматика без изменений.

## Привязка постановки к планам: по тексту, не по номеру
Шотлист перенумеровывают (341 → 342 → 351 → 352 плана), поэтому постановка привязана к плану ключом `'глава|начало текста плана'`
(`keys.js`): `shots.js` (`SHOTS`, `OVER`, `SKIP_PROPS`) и `clips3d.js`. Номера планов вычисляются из текущего `timing.json` при сборке.
После каждого перетайминга или правки шотлиста:
```
node production/L001/film/check.mjs --ch 0,1     # каждый ключ находит ровно один план; у каждого плана с героями есть постановка
```
Если план разрезали по словам — check покажет, какой ключ потерялся и какие новые планы остались без постановки.

## Как добавить план (главы 2–10)

1. Есть ли у локации конфиг в `staging/`? Нет — завести по образцу: плейт, точки посадки/стойки (пиксели плейта),
   масштаб `fs` (пикселей плейта на единицу фигуры), свет `noirShade(dir)` по источнику на плейте, полигоны переднего плана,
   базовые кадры `{cx, cy, k}` для общего/крупного/обратной.
2. В `shots.js` — запись `n: x => {...}`: база кадра `camView(V.xxx, cam)` (движение даст грамматика аниматика),
   действие героя из колонки «событие»: время — `s.snap`, `s.ev`, `s.whip`, `W_(x, 'слово')`; рот — автоматически.
3. Если событие уже нарисовано в кадре — добавить вещь в `SKIP_PROPS`, чтобы табличка аниматика не дублировала его.
4. Сборка, кадры `--stills`, полный рендер главы, `qa.py sheets` — и свой просмотр листов (чек-лист `QA.md`).


## Работа по главам: контракт рабочих (весь ролик, с 2026-11-18)

Главы делят три агента: **ведущий** — гл. 0–3 и все общие файлы; **рабочий A** — гл. 4–6; **рабочий B** — гл. 7–10.
Цель — не править один файл вдвоём и не ломать чужую сборку.

```

node production/L001/film/slots.mjs -- node engine/tools/render.mjs production/L001/film/entries/ch4_6/out/film.html <папка>/s --stills <кадр середины каждого плана>

node production/L001/film/final.mjs --ch 4,5,6 --entry ch4_6 --name ch4_6 # видео главы: 3D-сцены нативно, одно кодирование, голос, дорожки для звука

python production/L001/film/qa.py sheets production/L001/film/out/ch4_6.mp4 4,5,6
```
- **Браузерных рендеров на машине — не больше 2 одновременно, на всех агентов.** `final.mjs` берёт слоты сам; любые свои кадры
  `render.mjs --stills` запускайте через `slots.mjs -- …`. Состояние слотов: `node production/L001/film/slots.mjs --status`.
- Всё, что идёт дольше ~1 мин, — в фоне. Свободное место на C: не ниже 10 ГБ; свои промежуточные файлы удаляйте (`out/tmp/<имя>_*`, `out/tmp/ref_<имя>`, `out/tmp/c3d/<план>` после проверки — пересоздаются).
- Тайминг только из `animatic/timing.json` и `words.json` (их делает агент аниматика). Секунды руками не вписывать: события — на слове (`W_`, `W0`), иначе на `s.snap` / `s.ev`.
- 3D-план с готовой сценой (`scenes/*`) — запись в `clips3d/chNN.js` (сцена, `--set`, `dur: true` или `group`), не прокси аниматика.
  Какие сцены и куски уже использует аниматик — `animatic/core.js CLIP_OF`; параметры сцен — в шапке `scenes/<сцена>/film.js`.

### Правила картинки (Рауан, обязательно) — `wiki/craft/stickman-noir.md`, `wiki/craft/layering-and-motion.md`, `QA.md` этого фильма
- сидящий — по центру стула: на общем — нарисованный стул плейта, на крупном — `chairBack`; ноги ниже столешницы скрыты;
- никаких ног и тел вне проёмов (окна, двери): обрезка по проёму и по столешнице;
- предмет в руке — по правилу хвата (кисть-точка перед предметом, реальный масштаб: `office.keyGrip` — образец);
- стоящий — ступни на полу, контактная тень, ноги не дёргаются (`plantLegs`);
- рот — только на собственных словах героя (`words.js` делает это сам, если `sp` указан верно);
- герой целиком или чистая крупность (по грудь, по пояс); части тела из-за кадра без контекста — нельзя;
- каждый предмет понятен без слов, иначе убрать; надписи — шрифтом документов (`NOIR_FONT`);
- правило 3: реальные люди не показаны совершающими недоказанное; утверждения в кадре с источником (как в шотлисте);
- две одинаковые крупности подряд — нельзя (шотлист уже так построен — следуйте ему);
- проверка в полном размере 1920×1080, не миниатюры: каждый 3-й кадр каждого плана (`qa.py sheets`), непрозрачность `--set solo=k|w`
  (`qa.py opacity`), 3D-вклейка (`verify3d.py`, ИТОГ OK), речь (`speech_check.py`: 0 растянутых пауз, все слова распознаны), логика «понятно ли без слов».

### Отчёт ведущему по каждой паре глав

`QA_chN-M.md` (свой файл, не общий `QA.md`); честно — что слабо; какие новые герои, локации, ассеты сделаны.
