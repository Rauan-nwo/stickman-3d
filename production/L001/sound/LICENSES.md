# Лицензии звуковой библиотеки L001 (записи)

Файлы лежат в `production/L001/sound/lib/rec/<категория>/<id>.wav` (48 кГц, 24 бит; эмбиенсы стерео и зациклены
кроссфейдом, точечные звуки моно и обрезаны до транзиента). Оригиналы — `lib/_dl/<источник>/...`. Машинный реестр
со всеми полями — `lib/ledger.json`. Сборка — `tools/build_lib.py` (из `lib/picks.json`).

## Правила отбора

- Берём **только CC0 1.0 и Public Domain Mark 1.0**: без атрибуции, коммерция разрешена, Content ID не запрещён.
- Лицензия каждой записи с Freesound проверена **на её странице** (не только в Openverse) в день скачивания.
- Не берём: CC BY-NC / BY-ND / BY-SA, Sampling+, BBC (RemArc), «royalty free» без текста лицензии, перезаливы
  коммерческих библиотек (серийные имена вроде «R15-32-…», «PSE_», Hollywood Edge, Sound Ideas).
- CC BY — только если ничего другого нет, с явной пометкой и строкой атрибуции. **В этой библиотеке CC BY нет.**
- С Freesound берём HQ-превью (MP3 ~128 кбит/с), потому что оригинал WAV скачивается только через вход
  на сайт или ключ API. Формат оригинала записан в таблице — при желании его можно скачать тот же файл в WAV.
- Kenney: лицензия CC0 указана на странице набора и в `License.txt` внутри архива (оба текста — в
  `lib/_dl/kenney/kenney_meta.json`).


Всего файлов: **179** (906 МБ), из них Freesound — 177, Kenney — 2. Колонка «класс» — звуковой класс микшера (`render.py`), «z» — оценка earshot: насколько файл похож на описание нужного звука (от 3 — уверенно, 2–3 — правдоподобно; «слабый» — ниже 2.5 по исходнику или ниже 2 по готовому файлу).

## Не скачано: Sonniss GDC Game Audio Bundle — решение за Рауаном

- Где: `gdc.sonniss.com` — ежегодные наборы GDC Game Audio Bundle, ZIP-архивы от 7 ГБ каждый.
- Условия, как они заявлены у Sonniss: royalty-free, коммерческое использование разрешено, указывать автора не нужно;
  звуки можно использовать только в составе медиапродукции (видео, фильм, игра), раздавать сами файлы нельзя;
  использование для обучения ИИ запрещено.
- Это не CC0 и не Public Domain: это собственная лицензия Sonniss. Под правило этой библиотеки («только CC0 / PDM»)
  она не подпадает, поэтому в `lib/rec` из неё ничего нет.
- Почему не скачано: объём (десятки ГБ за несколько лет) и отдельная лицензия. Если Рауан решит брать — перед
  скачиванием перечитать текст лицензии на сайте в этот день, сохранить его копию рядом с архивом и завести
  в этом файле отдельный раздел с пометкой «лицензия Sonniss, не CC0».
