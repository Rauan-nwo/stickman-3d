## Как пересобрать (команды из корня проекта)
```
# голос: реплики героев своими голосами + темп (кеш, символы повторно не тратятся)
python engine/tools/voice_cast.py production/V002 --cast production/V002/cast.json --gap 0.16 --target 68.5 --pause "12:You=0.15,17:And=0.2"
# звук под текущие слова
cd production/V002 && python audio/make_audio.py words.json audio && python audio/mix.py voice_fast.mp3 words.json audio/mix_final.wav
# картинка + субтитры + звук + проверка
node engine/tools/make.mjs production/V002
```
Ключ ElevenLabs: `raw/_secrets/voice-api-key.txt` (не в git). Тариф бесплатный: осталось ~5 500 символов;
коммерческое использование на бесплатном тарифе, скорее всего, запрещено — уточнить у Рауана.

- Наложения в толпах: фигуры режутся по прямой, двоятся, затылки поверх лиц — исправлять причину в `engine/src/chars/crowd.js`, не отдельные кадры.

- Символы вместо действия не понятны: рука над мостом и «солдаты-шарики» убраны.
- Озвучка слишком быстрая; реплики героев — другими голосами; эффекты — свисты и всплеск «как на канале».
