# Откуда брать звуки для роликов канала

Практическая памятка по опыту V002 (2026-11-15). Всё, что здесь сказано о качестве, — по замерам и машинному
прослушиванию (earshot), не на слух. Лицензионные утверждения помечены: **проверено сегодня** / **по памяти, перепроверить**.

## ElevenLabs Sound Effects (`engine/tools/sfx_eleven.py`)

- Вызов: `python engine/tools/sfx_eleven.py production/V00N --name splash --prompt "..." --dur 3 --influence 0.6`
  или `--batch prompts.json`. Результат: `audio/gen/<имя>_<хеш>.wav` + `gen_log.json`. Одно и то же описание второй раз
  не отправляется (кеш по хешу). `--budget` не даёт выйти за лимит. В запросе уходит только текст описания.
- **Цена**: 10 кредитов за секунду заказанной длительности (подтверждено остатком в аккаунте: 72.4 с = 724 кредита).
  Остаток: `python engine/tools/sfx_eleven.py <фильм> --account`.
- Длительность 0.5–22 с. Короткие свисты заказывать по 0.6 с: звук занимает 0.2–0.3 с, остальное тишина.

**Что сработало**
- Одно событие, названный материал и действие, «Single event, no music, no voices»: *«One big heavy object plunging
  into deep river water: a loud clear splash, spray falling back, bubbling watery tail»*.
- Голоса: возраст + характер + «no words»: *«An angry older man gives one short furious growl… no words»*.
- Свист: *«Short tight airy whoosh, fast camera whip pan transition, soft high air, no low rumble, very brief»*.
- Масса: *«A large company of soldiers marching in perfect unison across a wooden bridge: heavy boots hitting hollow
  planks together…»* — получаются 5–6 отдельных ударов, которые режутся и ставятся на свои доли.
- `prompt_influence` 0.6–0.7 для точных звуков, 0.4–0.5 для вариантов.

**Что не сработало**
- **Целая сцена одним описанием** («бросок → кувыркание → пауза → всплеск»): вышел один стук, тишина и всплеск. Сцену
  собирать из отдельных звуков по меткам фильма.
- **Темп**: «at 88 beats per minute» не соблюдается. Мелодия флейты: AudioSet услышал «Trumpet 0.82».
- **Скрип верёвочных качелей**: не узнан (z 0.8, «шаги по листьям»).
- «Cloth-like swoosh» дал удар («Bang»), а не свист.
- Толпа на досках читается теггером как «цокот копыт» (Clip-clop 0.68) — использовать только тихим слоем.
- «Бормотание солдат» — слабо (z 2.1).

**Обработка**: генерации класть **сухими**. Реверберация «ущелья» уронила всплеск с z 4.2 до 2.7 («bang, fireworks»),
кувыркание барабана — с 3.0 до 1.6. Допустимо: обрезка, фейды, срез низа, плавное затухание и затемнение для «удаляется».

**Лицензия — не подтверждена.** Сегодняшний поиск дал противоречие: справка ElevenLabs — бесплатный тариф не включает
коммерческую лицензию; страница звуковых эффектов — на бесплатном тарифе нужна ссылка на elevenlabs.io, без ссылки и
для коммерческих проектов — платные тарифы. Текст приложения о звуковых эффектах в условиях ElevenCreative я не
прочитал. **Вывод для монетизируемого канала: считать сгенерированное на бесплатном ключе непригодным для публикации,
пока Рауан не подтвердит условия или не перегенерирует на платном тарифе** (описания и длительности лежат в
`gen/gen_log.json`, повтор стоит ~720 кредитов). То же касается голоса диктора.

## Openverse → Freesound, записи CC0 (`audio/openverse_fetch.py`)

- `https://api.openverse.org/v1/audio/?q=...&license=cc0,pdm`. Без ключа: 20 запросов в минуту, 200 в день. Отдаёт
  превью Freesound (mp3 ~128 кбит/с) — для эффектов под голосом достаточно; оригиналы WAV требуют входа на Freesound.
- Запросы — общие слова: источник + материал + действие («wood creak», «chain rattle», «man chuckling»).
  Пустые результаты: «rope swing tree creak», «swing set creak». Wikimedia отдаёт 429 при пакетном скачивании.
- Выбор: `earshot rank` по папке кандидатов → `earshot find` (чистый фрагмент) → `earshot describe` (AudioSet: первая
  подборка «смешков» оказалась покашливанием).
- CC0 и Public Domain Mark — без атрибуции и без запрета на коммерцию. Лицензию отдаёт Openverse; **перед публикацией
  открыть страницу каждой записи** (в V002 это не сделано). Не брать перезаливы коммерческих библиотек (признак —
  серийные имена вроде «R15-32-…»), даже если стоит CC0.

## Банк earshot (`C:\dev\tools\earshot`, MIT)

252 звука, рендер за секунды, без сети и без лицензионных вопросов (код; 15 «fit»-звуков сняты с записей CC0).
Силён: свисты, клики, тычки, колокольчики, UI. Нет: воды, скрипов, шагов, голосов, амбиенсов.
`earshot sfx render ID -o x.wav --dur 0.34 --apex 0.10` ставит пик свиста в нужную миллисекунду.

## Kenney (kenney.nl) — по памяти, перепроверить

Наборы игровых звуков под CC0: удары, UI, шаги, интерфейс. Маленькие, чистые, «мультяшные» — подходят стилю канала
для тычков, ударов и UI. В V002 не использовались и не скачивались; лицензию CC0 на странице набора проверить.

## Sonniss GDC Game Audio Bundle — по памяти, перепроверить

Ежегодные бесплатные наборы профессиональных библиотек: royalty-free, коммерческое использование разрешено, атрибуция
не нужна; нельзя перепродавать как библиотеку звуков. Очень большой объём (десятки гигабайт на выпуск). Это лучший
источник «дорогих» ударов, толп, амбиенсов и фоли. В V002 не скачивался (объём); текст лицензии в архиве прочитать —
в последних выпусках есть ограничения на использование для обучения ИИ.

## Чего избегать на монетизируемом канале

- **BBC Sound Effects** — лицензия RemArc: личное, учебное, исследовательское использование; коммерческое — только за
  отдельную плату (по памяти, перепроверить).
- **CC BY-NC, CC BY-ND, CC BY-SA** — запрет коммерции / производных / «копилефт» на весь ролик.
- **CC BY** — можно, но атрибуция обязательна в описании каждого ролика; проще не брать.
- «Royalty free» без текста лицензии, звуки из чужих роликов, библиотеки YouTube Audio Library вне YouTube.
- Mixkit, Pixabay — разрешают коммерцию без атрибуции, но запрещают регистрировать ролик в Content ID; Pixabay блокирует
  скачивание скриптом.
- Бесплатный тариф ElevenLabs — см. выше.

## Порядок работы на новом ролике

1. Спотинг по готовой картинке (`spotting.py`): список событий из кадров и `film.js`.
2. Синтез и банк earshot дают первый полный вариант за минуты.
3. `listen.py` показывает, что не узнаётся → для этих звуков записи CC0, для «героев» (вода, голоса, большие удары,
   свисты) — генерация, 2 варианта только на главное.
4. Каждую замену принимать только если её z выше прежнего; проверять уже обработанный стем, а не исходник.
5. `mask_check.py`, `stt_check.py`, `whoosh_check.py`, `check.py` → сборка `assemble.mjs` → `qa.mjs`.
